### 🧭 Como eu trabalho

- **Problema antes da ferramenta:** começo entendendo quem vai usar e o que precisa ser resolvido — seja um dashboard ou um sistema
- **Funcionando de verdade:** testo o que construo a cada etapa e publico o resultado
- **Organização:** estrutura clara de pastas, nomes padronizados e commits pequenos, com mensagens claras
- **Documentação que explica:** README com o problema, o processo, as decisões e as limitações de cada projeto
